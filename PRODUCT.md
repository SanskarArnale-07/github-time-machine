# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users
Primary users are developers reviewing their own coding history and reflecting on their journey. Secondary users include recruiters, hiring managers, and peers reviewing a developer's portfolio to understand their career trajectory.

## Product Purpose
To transform a developer's GitHub history into a cinematic documentary experience (a "Spotify Wrapped" for GitHub). It replays their journey through chapters, milestones, and moments of growth, allowing them to visualize progress emotionally rather than just statistically.

## Positioning
Unlike traditional analytical GitHub dashboards, GitHub Time Machine reconstruction is an emotional, narrative timeline that treats repositories as stories and commits as milestones in a career documentary.

## Operating Context
Users view this experience full-screen on the web. It serves as an engaging presentation often shared for end-of-year reviews, personal reflection, or as an interactive portfolio during job hunting.

## Capabilities and Constraints
- Full-screen cinematic playback with chapters, fade transitions, and film-inspired typography.
- Uses GitHub API to fetch real repository and commit data.
- Built with Next.js, React, TypeScript, Tailwind CSS, and Framer Motion.
- The interface must remain clean and focus heavily on the storytelling aspect of the generated data.

## Brand Commitments
The aesthetic is strictly "film-inspired" / "Spotify Wrapped" style (dark, dramatic, cinematic). The narrative tone must strike a balance between nostalgic/personal reflections and professional/analytical achievements.

## Evidence on Hand
- Next.js application structure configured with Tailwind CSS and Framer Motion.
- Supabase integration configured for backend and authentication.
- Core concept outlined in the README focusing on repository archiving, timeline navigation, and contribution heatmaps.
